# Runtime 术语表

> 这份表是**给人读代码用的索引**，不是第二个事实来源。它只写三样：一句话定义、「**不是**……
> 的边界」、以及出处链接；推导与实现细节留在 [`design/`](design/)、[`contracts/`](contracts/)
> 与源码里。判断一个词该不该收：**不是"重要"，而是"读者会以为自己已经懂了"。**
>
> 产品仓 `red-bean-nian-gao` 有它自己的一份，收宿主侧的词；两份都不复制对方的定义。

## 运行与检查点

- **checkpoint** — 一次运行的状态快照，由宿主负责持久化，按运行身份寻址。
  **不是**数据库 savepoint，**不是**备份点：它带一个单调递增的 revision，是并发控制的载体。
  <a id="checkpoint"></a>

- **checkpoint revision** — 快照的版本号，每次成功保存以 CAS 递增（R → R+1）。
  **不是** HTTP ETag，也**不是**数据库行版本——形式像，但它是宿主写入时的乐观锁依据。
  <a id="revision"></a>

- **CAS** — 保存 checkpoint 时的 compare-and-swap：以「我读到的是 R」为前提写入 R+1，
  陈旧 revision 的写入必须被拒。SDK 只定义这条协议，**不实现存储**。
  <a id="cas"></a>

- **claim（resume claim）** — 从挂起态**认领**一次恢复。
  **不是**「声称」，**不是**互斥锁——它记录的是「谁认领了这次恢复」，不是「谁排他地占着」。
  见 `runtime/checkpoint/`。<a id="claim"></a>

- **suspended / `AWAITING_USER`** — 运行停下来等人工确认。
  它是**唯一**「没跑完但也不是失败」的取值；当成失败处理会让流程跳过等待。
  <a id="suspended"></a>

- **thread** — 一条持续对话的运行线索，跨多次 run。
  **不是**操作系统线程，**不是**并发单位——它只是「这些 run 属于同一条线索」这个身份。
  <a id="thread"></a>

## 并发与一致性

- **fencing token** — 宿主租约系统发放的单调令牌：旧持有者以更小的 token 写入会被拒。
  **不是**鉴权 token，**不是**会话 ID——它的作用只有一个：让过期的写入者无法生效。
  <a id="fencing-token"></a>

- **幂等键（idempotency key）** — 调用方给一次请求起的名字，用于让重试产生一次副作用而非多次。
  **不是**去重缓存：它约束的是「同一个请求重复到达」，不是「相同内容只算一次」。
  <a id="idempotency"></a>

- **重放（replay）** — 对一次已经结束的恢复请求**再次提交**，按已记录的结果应答而不是重新执行。
  **不是**重试：重试是请求没成功，重放是请求已经成功过。 <a id="replay"></a>

- **fail-closed / fail-open** — 出错时默认拒绝 / 默认放行。本仓的**文件与网络工具默认 fail-closed**，
  必须由宿主显式选择并授权。**不是**错误处理策略，是安全默认值的取向。 <a id="fail-closed"></a>

## 中断与收尾

- **interrupt（中断屏障）** — 一批工具里只要有一个要求人工确认，**同批其余工具都不执行**，
  整个运行进入挂起态。判据是工具声明里的静态 `interrupting`，运行期返回的信号不参与判定。
  **不是**「跳过那一个调用」——屏障消失了，另外几个工具就已经跑完了。
  <a id="interrupt"></a>

- **取消（cancel）** — **运行**被外部中止，表现为 `AbortSignal` 的 abort。
  <a id="cancel"></a>

- **中止（abort）** — **信号**被置为已中止，或**单个工具**被停止。
  与「取消」是不同主体：信号中止是取消的**表现**，而工具超时中止与整次运行无关。 <a id="abort"></a>

- **收尾（finalize / finally 节点）** — 无论成败都要跑完的清理阶段，**取消已发生也要跑**。
  **不是**取消语义，**不是**「关闭预算」——收尾有自己的超时上限，那个上限是第三件事。
  <a id="finalize"></a>

## 上下文与计量

- **Token（本仓）** — **粗略估算**，不是真实分词：ASCII 约 4 字符 1 Token，非 ASCII 按 1 字符 1。
  只用于压缩触发的量级判断。**别拿它当计费或精确上下文长度。** 见 `pipeline/compression/token-counter.ts`。
  <a id="token"></a>

- **compression（压缩）** — 本仓模块名（`pipeline/compression/`）。产品仓把同一件事的**持久化事实**
  叫 `compaction`；那是它 wire 契约里的既有名字，两边指同一件事，不是两个机制。
  <a id="compression"></a>
